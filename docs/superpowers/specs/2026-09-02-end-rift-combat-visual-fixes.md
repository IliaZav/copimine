# End Rift Combat and Visual Fixes Specification

**Date:** 2026-09-02
**Repository:** `IliaZav/copimine`
**Branch:** `codex/end-rift-event`

## Goal

Исправить нестабильный урон по event-мобам и боссу, сделать портал и заклинания заметными, добавить безопасные зоны с изумрудным визуалом, убрать бесконечное инвертированное управление, стабилизировать ИИ босса и сделать чистые цельные модели End Rift.

## Boundaries

- Работать только в локальном checkout и локальном Paper/Purpur runtime.
- Боевой сервер, боевые базы данных и боевой мир не открывать и не изменять.
- Текущую локальную карту сохранять; не делать wipe, regenerate или reset мира.
- Не менять глобальные vanilla-текстуры и поведение обычных fireball/мобов вне End Rift.
- Сохранять virtual HP, стадии, награды, persistence/recovery, cleanup и клиентский протокол.
- Safe-зоны реализовать event-owned `BlockDisplay`/particle-visuals без временной записи `EMERALD_BLOCK` или `BEACON` в мир.

## Approved behavior

- Урон, уже отменённый другим обработчиком, не меняет authoritative virtual HP босса.
- Обычные подтверждённые атаки игроков по event-мобам и боссу не теряются из-за event-логики.
- Урон волновых мобов и мини-боссов уменьшается на 4, с нижней границей безопасного значения; урон босса не изменяется этим правилом.
- Safe-zone objective длится 60 секунд по умолчанию и настраивается конфигурацией.
- На safe-зонах видны изумрудные event-owned площадки и зелёные вертикальные лучи; cleanup удаляет только event-owned объекты.
- Босс удерживает цель с гистерезисом и не переключается между доступными игроками на каждом коротком тактическом цикле.
- Инвертированное управление действует ровно 10 секунд на один запуск и корректно очищается при истечении, смене поколения и cleanup.
- Порталы используют существующие event-only custom model/data пути; обычные vanilla-модели не заменяются.
- Заклинания босса имеют заметные серверные телеграфы, полётные следы, impact-эффекты и звуки, с bounded particle budget.
- В wave 3 порталы имеют чёрно-фиолетовый рифтовый визуал; vanilla-портал и глобальные vanilla-текстуры не меняются.
- Мобы wave 3 не получают от portal objective искусственного отталкивания/velocity-пинка.
- Прогресс захвата портала после выхода игрока не сбрасывается мгновенно: процент постепенно уменьшается по отдельной настраиваемой скорости до нуля.
- `RIFT_OBELISKS` запускается не более одного раза за бой, только в `DISTORTION`, виден игроку и полностью очищается.
- Модель босса становится выше и уже, а event-модели используют цельные симметричные материаловые зоны без случайной пиксельной зернистости.

## Acceptance evidence

Работа принимается только при наличии свежих результатов:

1. Unit/contract tests для damage, target lock, zones, controls и obelisk visibility.
2. Сборка server plugin и client mod без ошибок.
3. Resource-pack ZIP с проверенными моделями/текстурами и совпадающим SHA1 HTTP-ответом.
4. Local live tests для обычного моба, босса, portal objective, safe-zone objective, spell visuals и `RIFT_OBELISKS`.
5. Performance smoke с пятью игроками и bounded entity/particle counts.
6. Локальный restart с сохранённой текущей картой и без обращения к production endpoints.
