# Волна 4 — Штурм обелисков

## Утверждённая механика
Обелиски — настоящие текстурные 3D-объекты, а не простые белые/одноцветные блоки. Визуальные состояния здоровья: полный, повреждённый, критический, разрушенный. Каждый обелиск имеет ТРИ единицы здоровья; один точно отражённый событийный огненный шар снимает ровно одну единицу. Обычные удары не заменяют правильную механику. Разрешено до шести обелисков по масштабированию, фактический профиль проверять из конфига. Выделенные attack/reflect/collapse окна; атаки не голодают из-за другого планировщика. **Будущую линию полёта/точку попадания НЕ показывать** — это прямое решение пользователя.

## Ранее сообщённые проблемы
Модель выглядела обычными блоками, неверные UV/наложение текстур, текстура не менялась при получении урона, разрушение скачкообразно меняло размер, специальных атак не было, снаряд не отражался/не учитывался. Отдельно старый код позволял рассинхрон timing/hit count.

## Состояние
Код содержит идентификаторы FULL/DAMAGED/CRITICAL, проверки трёх HP и историю исправления Wave4 special-attack starvation / collapse. Проверенная в 26.3 F2 анимация всех состояний отсутствует.

## Приёмка
У каждого обелиска три валидных reflected hits, 3→2→1→0, ровно один урон за один снаряд, без обычного оружия. Реальный отражённый снаряд должен иметь точные eventId/generation/owner/hit identity; чужой/повторный снаряд не засчитывается. Снимки всех 4 состояний с разных сторон, текстуры без белых fallback, destroy/restart/cleanup, корректный таймер.
