# Анимации луков и арбалета CopiMine

## Цель

Добавить кастомные пиксельные текстуры и ванильно совместимые состояния натяжения для новых луков, взрывного арбалета и записок, не меняя старые текстуры, клиентский мод или мир.

## Дизайн

Ресурс-пак будет использовать обычные `CustomModelData`-overrides в моделях `minecraft:item/bow`, `minecraft:item/crossbow` и `minecraft:item/written_book`. Ванильные predicates сохраняются в исходном порядке, а кастомные правила добавляются после них и проверяют одновременно `custom_model_data` и состояние предмета.

Для каждого лука создаются базовая модель и три кадра натяжения (`pulling_0`, `pulling_1`, `pulling_2`). Для арбалета создаются базовая модель, три кадра натяжения, заряженное состояние со стрелой и заряженное состояние с фейерверком. Пороговые значения `pull`, а также predicates `charged` и `firework` остаются ванильными.

Новые значения `CustomModelData`:

- `10014` — лук телепортации;
- `10015` — лук блоков;
- `10016` — взрывной арбалет;
- `10017`–`10024` — восемь записок, использующих одну общую модель книги с пером.

Текстуры будут настоящими 16×16 RGBA PNG с жёсткими пиксельными кластерами и ограниченной палитрой. Для арбалета кадры будут симметричными по силуэту, чтобы стадии натяжения не дёргались. Записки используют один общий визуальный файл и отдельные CMD только для однозначного выбора каталожного предмета.

## Совместимость и ограничения

- Не регистрировать новые Minecraft item ID.
- Не добавлять обязательный клиентский мод или новый network protocol.
- Не изменять старые PNG и существующие модели артефактов.
- Не менять варку, лавку, базы данных или мир.
- Локальный стек перезапускается только после сборки; production не запускается и не получает файлы.

## Проверка

Добавить regression-контракты, которые проверяют:

1. CMD и каталог новых предметов;
2. наличие базовой модели и всех кадров;
3. сохранение ванильных bow/crossbow predicates;
4. наличие `charged`/`firework` для арбалета;
5. размер 16×16 и RGBA у новых PNG;
6. наличие всех новых файлов в собранном ZIP и совпадение SHA-1;
7. отсутствие изменений в старых tracked PNG.

После реализации выполнить focused tests, сборку resource-pack, сборку `CopiMineArtifacts.jar`, локальный restart и проверку HTTP ZIP/активных портов.
