# End Rift Event Audit Remediation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to execute this plan task-by-task with review checkpoints.

**Goal:** Bring the End Rift event from the published baseline to a verified implementation that satisfies the v3 specification, including deterministic client assets, authoritative server behavior, restart-safe lifecycle, Wave 6/7 correctness, and native Minecraft visual/runtime evidence.

**Architecture:** Keep server authority in `copimine-end-event` and pure domain policies; keep Bedrock/Fabric conversion, model selection, animation playback, HUD, and renderer safety in `CopiMineClient`; keep distributable client/resource-pack artifacts generated by their existing build scripts. Every behavior change gets a focused failing contract or policy test before implementation, then a clean build and runtime probe. Native Minecraft captures are evidence only after the exact built artifacts are installed and the server state is identified.

**Tech Stack:** Java 21, Paper/Bukkit event plugin, Fabric client mod, Minecraft 1.21.1, Gradle, PowerShell, Python contract tests, JUnit/pure Java policy tests, GitHub branch `codex/end-rift-event`, bundled ffmpeg for local captures.

**Spec:** `docs/superpowers/specs/2026-09-10-end-rift-event-v3-final.md`; objective source: `C:/Users/zavod/.codex/attachments/9f625346-251e-44d1-8dd2-b6d4bc84d0f4/goal-objective.md`.

## Global Constraints

1. Preserve the dirty user worktree and the clean detached baseline worktree. Do not reset, checkout, or discard unrelated changes.
2. Before every production-code change, reproduce a concrete symptom and add a failing test at the narrowest available layer. Keep projectile mechanics unchanged unless a new reproduction and regression test proves a projectile bug.
3. Treat static contracts, build success, hashes, and logs as separate evidence from live Paper behavior and native Minecraft visuals. Do not call a source/config result a production result.
4. All temporary blocks/entities must be owned by event id and generation, journaled before mutation, reconciled on bootstrap, and cleaned idempotently with original block restoration.
5. Any unsupported geometry, UV, pivot, transform, or animation construct must fail loudly with diagnostics; no silent fallback that presents an incorrect model as correct.
6. Final verification must include exact baseline/final commit and tree, per-issue status, artifact hashes, runtime matrix, native screenshots/videos when available, and a literal `UNRESOLVED ITEMS` section. If native QA cannot be completed, include the exact phrase `REAL MINECRAFT VISUAL VERIFICATION NOT PERFORMED`.
