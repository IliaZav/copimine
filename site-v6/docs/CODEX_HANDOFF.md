# Поддержка CopiMine v6

## Точки входа

- index.html / CopiMine_v6.html: автономный просмотр с тестовым состоянием.
- server-index.html: выдаётся только сервером, данные через аутентифицированный API.
- server.py / server/: рабочая логика и операторские команды.
- integrations/game-bridge/: типизированный подписанный мост в фактические плагины.

## Модули интерфейса

domain-v6.js — валидация корзины, лимитов, срока и безопасного CSV.
site-v6.js — общая оболочка, корзина, донат, cookies, объединённый кабинет.
players-v6.js — карточка игрока, инвентари и формы действий.
map-v6.js — Canvas и публикации трёх миров.
bridge-v6.js — API, сеанс, согласование серверного состояния.
admin-v6.js — каталог, материалы, финансы, аудит, доступ и CMS.
analytics-v6.js / search-v6.js — сбор событий, отчёты и общий поиск.
polish-v6.css / v6.css — адаптивная вёрстка и анимации.

Старые v4/v5 модули остаются базой оболочки и вспомогательных компонентов. Их демонстрационные мутации закрыты в рабочем режиме; добавляя новый контрол, явно подключай типизированный API. Не добавляй доверие к полям role, balance или recipient из браузера.

## Источники и сборка

Используй источники из docs/SOURCES.md, сохраняя game ID и утверждённые display names. Не подменяй выбранную items.yml просто более новой по дате веткой с несовместимыми предметами. Материалы, каталог магазина и рецепты — разные реестры.

После изменения исходников: выполнить необходимые проверки, python build.py, python scripts/package_release.py. В итоговую публикацию не включать v5 HTML, SQLite, секреты, raw world и промежуточные рендеры. release-manifest.json формируется упаковщиком.

## Проверки

docs/QA.md и docs/verification.json содержат проверки текущей версии. Для финансов, прав, подтверждений и очередей сначала сохраняй инварианты идемпотентности, затем меняй интерфейс. Не обозначай транспортное принятие команды её исполнением. Для таймеров используется серверный worker, а не только клиентский отсчёт.

## Эксплуатация

Руководство установки — docs/DEPLOYMENT.md. Производственная конфигурация хранится вне каталога сайта. Операторские секреты и данные действующего мира не являются частью исходников.
