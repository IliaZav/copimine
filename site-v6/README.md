# CopiMine v6

Полный сайт: магазин, донаты, карты трёх миров, личный кабинет и управление сервером. В архиве находятся интерфейс, все изображения и карты, API на Python, база каталога, игровой адаптер, сборщик плагинов, тесты и инструкции запуска.

## Посмотреть сайт

Распакуй архив. Открой **CopiMine_v6.html** или **OPEN_DEMO.bat**: всё необходимое для просмотра уже внутри HTML. **START.bat** запускает локальный просмотр через Python; без Python он открывает тот же HTML.

Панель внизу позволяет переключиться между игроком и администратором. Это отдельный режим просмотра с примерами данных. На рабочем сервере такой панели и переключения ролей нет.

## Что изменено

- Профиль, обычный инвентарь на 41 ячейку и эндер-сундук на 27 ячеек объединены. Карточка игрока содержит покупки, донаты, балансы, наказания, лимиты и историю.
- Действия администрации сгруппированы: предметы, экономика, ограничения, перемещение, состояние игрока, проверки и игровые эффекты. Формы содержат нужные параметры, причину и сроки; временные ограничения можно отменять.
- Магазин использует проверенный каталог и сохранённые переименования. После добавления товара появляется счётчик количества. Корзина проверяет общие и предметные лимиты, привязку и допустимое количество.
- В выборе суммы доната сохраняются способ оплаты, сумма, согласие и фокус. Предусмотрены создание платежа, продолжение оплаты, проверка статуса и история.
- Настоящие карты Обычного мира, Незера и Энда построены из предоставленного архива. Есть масштабирование, координаты, полный экран, ручное обновление, расписание и управление маркерами игроков.
- Поиск находит разделы, игроков, предметы, заказы и действия; понимает опечатки и неверную раскладку. Аналитика показывает популярные товары, покупки, платежи, воронку и события с учётом согласия.
- Редактор товаров, страницы, публикации, FAQ и галерея сохраняются сервером с проверкой версии. Причины изменений доступны администрации.
- Почта и телефон подтверждаются кодом; доступны вход по коду, восстановление пароля и VK ID. Для администрации второй фактор сохраняется при любом способе входа. Отправка через SMTP/TLS и SMS.RU идёт отдельной очередью.
- Добавлены адаптивные состояния, анимации с учётом уменьшенного движения, баннер cookies с иллюстрацией и крупный пиксельный favicon.

## Запустить рабочий сайт

Рабочий режим запускается через **server.py**, а не публикацией файла для просмотра. Он использует серверные аккаунты, роли, сеансы, двухфакторную аутентификацию и подписанный обмен с игровым сервером.

Порядок установки — в **docs/DEPLOYMENT.md**. Подробности игрового адаптера — в **integrations/game-bridge/README.md**. Карта — **docs/MAP_RENDERING.md**. Источники предметов и текстур — **docs/SOURCES.md**. Почта, SMS и VK — **docs/AUTH_PROVIDERS.md**.

Для работы на твоём хостинге нужно один раз создать владельца, указать пути к мирам, установить собранные плагины и настроить секреты адаптера, платежей, SMTP, SMS.RU и ID приложения VK. Для настройки способов входа предусмотрен мастер `python scripts/configure_auth.py --config ПУТЬ_К_ЗАКРЫТОМУ_JSON`. В архиве нет паролей от твоего сервера или платёжного кабинета. Проверки выполнены изолированно; эта сборка сама не устанавливается на действующий Minecraft-сервер.

## Состав

| Путь | Назначение |
|---|---|
| CopiMine_v6.html | Один файл для просмотра без сети |
| index.html, assets/ | Исходный интерфейс и изображения |
| server.py, server/ | Рабочие аккаунты, API, платежи, права, каталог и очереди |
| integrations/game-bridge/ | Подписанный игровой адаптер и расширения плагинов |
| data/, sources/ | Зафиксированные каталоги и происхождение материалов |
| scripts/ | Сборка HTML, рендер карт, проверка и упаковка |
| deploy/ | Образцы конфигурации и служб |
| docs/QA.md | Выполненные проверки и их границы |
| release-manifest.json | Перечень файлов архива и SHA-256 |

Пересобрать HTML: `python build.py`. Создать ZIP: `python scripts/package_release.py --output ../CopiMine_Site_v6_Full.zip`.
