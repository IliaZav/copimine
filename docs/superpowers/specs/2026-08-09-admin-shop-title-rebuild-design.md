# Перезагрузка надписей лавок в админском GUI

## Цель

Добавить в GUI лавок администратора кнопку, которая восстанавливает подписи над лавками из актуального состояния PostgreSQL и удаляет зависшие подписи, оставшиеся от удалённых лавок.

## Поведение

1. Кнопка запускает DB-refresh в фоне, чтобы не блокировать Bukkit main thread.
2. Сначала полностью успешно перечитывается `artifact_shops`; при ошибке БД визуальные сущности не удаляются.
3. На основном потоке удаляются только сущности с PDC-типом `SHOP_TITLE_DISPLAY` — чужие `TextDisplay` по видимому тексту не затрагиваются.
4. Подписи создаются только для лавок из свежего DB-снимка, у которых загружен мир, чанк загружен, лавка включена и якорный блок существует.
5. После операции GUI показывает результат: сколько подписей удалено и создано. Сами лавки, мир и таблицы БД не изменяются.
6. При загрузке чанка orphan-подписи также удаляются по PDC ownership, чтобы старый текст не возвращался после последующей загрузки чанка.

## Проверка

- Контрактный тест проверяет кнопку и маршрут действия.
- Контрактный тест проверяет DB-refresh перед удалением и создание только из `shopsByLocation`, заполненного PostgreSQL.
- Существующие проверки layout/title/visual ownership остаются зелёными.
- После сборки серверный JAR сверяется с локальным SHA-256; Minecraft перезапускается без wipe/rollback.
