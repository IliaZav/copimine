## Evidence Rules

- A source trace identifies a plausible or confirmed code-path defect; it does not prove player-visible behavior.
- A passing source contract or unit test proves only the assertion it covers.
- A successful build proves compilation and packaging only.
- Minecraft claims require a real Fabric client connected to the rebuilt isolated Paper server, with build hashes and capture metadata.
- No real Minecraft client session or screenshot has been captured for this repair pass. The currently available CUA surface reports no native apps; isolated Paper server probes are recorded separately below.
