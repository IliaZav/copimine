CopiMine Launcher 1.0.1

Версия 1.0.1 · 2026-08-17T05:00:00Z

  • Minecraft, Java и обязательные моды теперь загружаются из хранилища CopiMine.
  • Добавлена проверка и восстановление локального runtime-архива Minecraft 1.21.1.
  • Обновлён установщик с выбором папки и встроенным резервным способом восстановления.

Установка игры

Файлы CopiMine

  • addedLauncher получает Minecraft 1.21.1, Fabric Loader 0.19.3, Java 21 и набор модов по подписанному manifest с адресов CopiMine.
  • fixedПовреждённая или неполная загрузка runtime не заменяет рабочую установку: файл сначала проверяется по размеру и SHA-256.

Моды

Основной набор

  • changedВ manifest закреплены CopiMineClient, CustomSkinLoader, EmoteCraft, Fabric API, Simple Voice Chat, Iris и Sodium.
  • addedMod Menu устанавливается вместе с набором, но остаётся необязательным для admission.

Исправленные ошибки

Подготовка игры

  • fixedУбрана зависимость production-пути provisioning от внешнего Mojang/Fabric download fallback: при отсутствии server-hosted runtime Launcher сообщает точную причину.
