CopiMine Launcher 1.0.0

Версия 1.0.0 · 2026-08-15T12:00:00Z

  • Добавлена установка отдельного Minecraft 1.21.1 с Fabric Loader 0.19.3.
  • Файлы клиента синхронизируются по подписанному manifest с восстановлением после сбоя.
  • Сервер mc.copimine.ru добавляется автоматически без удаления других серверов.

Общие изменения

Установка игры

  • addedLauncher устанавливает Java 21 и отдельный экземпляр игры, не изменяя пользовательскую основную папку Minecraft.

Технические изменения

Обновление файлов

  • fixedНезавершённая или повреждённая загрузка не заменяет рабочую версию managed-файла.

Вход на сервер

  • verifiedСовместимый CopiMineClient подтверждает protocolVersion коротким READY→ACK handshake.

Исправленные ошибки

Старые ссылки

  • changedСтарая страница модпака ведёт к установщику Launcher, а ручной ZIP остаётся только аварийным legacy-артефактом.
