# Глобальные правила End Rift

## Разработка и архитектура
Порядок: модели/текстуры/анимации → волны 1–7 → Rift Guardian → Kagune → полный системный аудит. Совместимость Minecraft 26.3 — базовое окружение, не повод снова переписывать весь сервер.

Сервер Paper владеет событиями, целями, состояниями, уронов, наградами, таймерами, попытками и восстановлением; Fabric CopiMineClient отображает модели, HUD, шейдеры, подсветку и ввод пленника. Один владелец каждого перехода состояния. Любая отложенная задача проверяет eventId + generation + активную фазу/роль. Обычная игра и отладочный режим должны использовать одинаковую механику.

Полный жизненный цикл: начало → предупреждение → цель → действие → попадание/промах → завершение → очистка. Смерть, выход, смена мира, перезапуск, повторный запуск, закрытие чанка, отменённый удар, прежний пакет, неудачное создание объекта и прерванное восстановление обязаны иметь определённый исход. Переход на новую попытку невозможен пока не очищены/не восстановлены ресурсы прежней.

Избегать технических надписей и внутренних имён на экране, банальных атак «тот же снаряд другого цвета», секторов пола, самонаводящихся снарядов и бессмысленного прироста HP. Предупреждения — понятные формы частиц, позы и звуки. Глобальные эффекты не портят настройки Iris/пользователя. Не нарушать чужие защищённые блоки, инвентарь, сохранения и PostgreSQL.

## Общий цикл из семи волн
- После начала волны руны исчезают. Между волнами 1–6 появляется возможность запустить следующую только после 10 секунд непрерывного удержания нужными живыми участниками на рунах. Нельзя дважды запустить волну.
- После 7-й руны не появляются.
- После 7-й немедленно полностью восстановить здоровье участников и вернуть 30% от МАКСИМАЛЬНОЙ прочности каждой повреждённой вещи (с ограничением максимума и сохранением ID/метаданных).
- Затем РОВНО ОДИН общий 40-секундный переход/кинематографический эпизод до боя с боссом. Не добавлять сверху ещё 20 или дополнительные 40 секунд.
- Ресурспак, геометрия, эффекты и музыкальные события синхронизированы со стадией, при прерывании очищаются.
- Реальные тесты для 2 игроков; отдельно нагрузка 5–6 игроков. Отладка одного игрока допустима, но не должна молча изменять официальные правила для группы.

## Баланс
Игрок должен понимать причину попадания, видеть предупреждение и иметь контрприём. Сильные атаки имеют каст и ограниченную частоту. Мобы активно перемещаются, выбирают правильные цели и дают стандартную реакцию на принятый урон; отказанный урон не вызывает ложной вспышки. Защитные навыки, блоки, снаряды, броня, зоны и заглушенные AI должны соблюдаться на сервере.

## Тестовые команды
В текущем коде есть /cmend status, /cmend debug objectives, /cmend debug ai, /cmend debug hazards, /cmend debug invariants, /cmend test wave 1–7, /cmend test wave 6 capture/combat, /cmend test showroom, /cmend boss phase, /cmend wave clear. Перед применением СВЕРЯТЬ точный синтаксис и полномочия из действующего Java command handler. Все команды — только на изолированном сервере, не смешивать с официальным PvE и наградами.
