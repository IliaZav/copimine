## Corrected and regression-tested

1. **Clean-checkout startup failed.** The unanchored `data/` ignore rule omitted required `frontend/data` inputs. Eight vetted existing reference files are now packaged, while root runtime `data/` stays ignored.
2. **Administrative JSON could be served as public data.** Action definitions now live in `private/admin-actions.json`; a strict eight-file public allowlist replaces the `/data` directory mount. Authenticated actions still use the protected API.
3. **Guest bootstrap leaked privileged bridge health.** Public health exposes only online/ready/count/capacity/version. Full plugin lists, player identifiers, private paths and diagnostics remain behind administrative permissions. Filtering does not mutate the shared cache.
4. **Local transfer rejection stranded idempotency keys.** PIN/quoted-fee validation now precedes reservation. Rejected local inputs create no receipt or dispatch. A corrected request can reuse its original key; an accepted replay dispatches only once.
5. **Malformed checkout input could fail with HTTP 500 or reach the game prematurely.** Validate linked identity, structured rows, string IDs, exact integer quantity, supported currency, positive bounded total and PIN before reserving or dispatching.
6. **Rejected uploads destroyed existing valid assets.** Scan a separate same-directory candidate, then atomically replace only after a clean verdict. Infected/unavailable/failed scans preserve the previous file and remove temporary candidates where possible.
7. **Production template credentials/origin were accepted.** Obvious placeholder/degenerate SECRET_KEY values and invalid non-HTTPS or credential-bearing origins now prevent startup. No deployment credentials were rotated.
8. **Optimistic catalog revision omitted the image.** Image-only edits now change the version, preventing stale catalog writes from silently overwriting them.
9. **Reverse-proxy upload limits contradicted the API.** Nginx now accepts the API's 12 MiB JSON limit and allows a bounded 120-second scan to finish. Runtime `nginx -t` is still required before deployment.
10. **A blank compass search alias appeared in both release catalogs.** Corrected the alias, preserving the stable game item ID.
11. **Website branch had no workflow.** Added independent clean-checkout Python tests and delivered-JavaScript syntax checks for site push/PR branches. This does not replace the Minecraft branch's workflows.
