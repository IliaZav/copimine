### §7 GIANT CENTER-CORE CHEST BEAM / NUKE (обязательный «ульта»)

- `chest_beam`: hue `0xE040FF` (магента), END_ROD + DUST_MAGENTA, вихрь 3.5,
  звук `ender_dragon.growl`, силуэт «core chest beam».
- Смотреть по шагам §7.1: (1) босс уходит на Core по видимой траектории;
  (2) заряд 2–3 с — открывается грудная броня, слоистое ядро, орбита осколков,
  магента+циан сжимаются в грудь, **луч-дорожка читается даже в дыму**;
  (3) выстрел точно по замороженным линиям (2–3 дорожки по числу игроков);
  (4) последствия — утихающие ленты, временные косметические выжженные блоки,
  короткий стан и возврат в бой.
- КРИТИЧНО: луч НЕ поворачивается за убегающим (aim-lock на момент фиксации),
  укрытие между Core и целью реально останавливает удар, игрок вне дорожки не задет.
  Доступен только RIFT/OVERLOAD/RAGE, не в LAST_SEAL; имеет заметный кулдаун.

## 2. Фаза 5 RAGE — Echo-копии (§6, §9, канон)

- Копия воспроизводит **недавнее реальное** действие игрока (силуэт оружия/жеста),
  потом взрывается после понятного предупреждения. Владелец должен **узнать своё**
  оружие и отличить копию от союзника.
- НЕ должно быть зеркалирования непознанных модифицированных payload'ов и
  неизбежного self-damage цикла.

## 3. Фаза 6 LAST_SEAL — Kagune (обязательный §9G)

- **Защитный Kagune** (`kagune_*`/main tentacle): ~4.5–5 блоков, толстая база,
  сегментированное тело, полумесяц-наконечник, внутренние филаменты Разлома,
  матово-тёмно-фиолетовая кожа, вены по мышце. Проверить состояния урона и
  анимацию атаки, а не статичную «палку».
- **Кольцо Kagune**: радиальное окружение с реальными проходами 2 блока.
- **Seal Lance Volley** (§6 стр.313 / §9G.03): залп **по 2–3 игрокам** (не в одного),
  короткий, со ступенчатыми импактами.
- **Ambush Grab** (§9G.04): одно явное предупреждение → реальный захват → бросок →
  полный отход; 100 % по владельцу-решению.
- **Small Kagune** (§9G.05): реально меньше главного, конечное число
  (`max-active`, на проде 30), реально бьёт и преследует, legible hitbox,
  полноценная смерть без трупа; не пропадает от одного обычного тычка.
- **Cocoon Pressure** (§9G.06): пока идёт оборона, Страж **обязан непрерывно**
  кастовать групповые заклы — не должно быть пустого простоя.

## 4. Волны — визуал (снять по одному кадру на пункт)

- **W1 Rift Carriers**: элита-носитель, реальный перенос заряда, кольцо сжатия
  green→red по стадии, луч Slow II только для настоящего носителя/адресного зрителя.
- **W2 Rift Gaze**: ~70 фантомов, 3 группы, все игроки помечены весь заход;
  статуя/силуэт стоит, смотрит, встаёт/открывает рот при выборе и материализуется
  в реального Enderman. Отделять настоящий ванильный `EntityType.PHANTOM` от
  клиентской модели-призрака. Никакого дрожания шейдера, музыка без рестарта.
- **W3 Rift Gates**: портал реально открывается, спавнит мобов, живёт свою боевую
  жизнь, сигналит захват, складывается трёхслойной 3D-моделью. Elite Giant Zombie —
  читаемая аура, тяжелый удар, видимый hitbox; Elite Skeleton — тройной залп,
  дождь стрел; Enderman-кастер; Spider WEB + confusion.
- **W4 Obelisk Assault**: обелиски — физические выразительные конструкции,
  состояния урона, стреляют по реальным игрокам с предупреждением и коллизией,
  взрываются; 3 валидных отражённых шара на обелиск (≤6 обелисков).
- **W5 Black Fog**: ровно 5 циклов; разница кадра **внутри** и **вне** safe-зоны
  при той же позиции/угле; внутри — чистая камера, без небезопасных эффектов;
  снаружи — плотный объём, мобы не стоят в safe-зоне; Iris и vanilla совместимы.
- **W6 Ritual Sphere / Rift Ram**: 4 обычных + финальный столп, семь **реальных**
  ударов; броня показывает удар щита и НЕ теряет HP до пробоя; череп — СВЕРХУ
  платформы; падающий скелет выживает и переходит в наземный бой. Коллайдеры
  физические (можно стоять). Пустой бар/сирота-скелет/блок апгрейда недопустимы.
- **W7 Reality Split**: вход по официальному завершению W6 + руны, не тест-команда.
  Одна арена, **четыре последовательных** поимённых миниибосса
  (WARDEN → MOBILE_MARKSMAN → RIFT_ARCHMAGE → PERSONAL_ECHO) — порядок сверить с
  живым кодом. Каждый бьёт своими атаками и своим hitbox, своя полоска; убийство →
  чисто → следующий; в конце полный хил, +30 % прочности повреждённых предметов,
  один 40-секундный переход к боссу без двойного отсчёта.
