# ИИ Хранителя Разлома

Это компактный поведенческий контракт босса. Все решения принимает один
контроллер события на серверном тике; случайность не используется для
маршрута, а каждая позиция проходит общие проверки арены.

## Фазы

| Фаза | Поведение | Заклинания |
| --- | --- | --- |
| Пробуждение | держит кольцо вокруг ядра и меняет сторону орбиты | `void_blast`, `rift_projectile` |
| Охота | короткий фланг по отношению к выбранному игроку | `rift_arrows`, `void_mark` |
| Искажение | пересекает линию атаки и один раз делает обратный финт | `will_distortion`, `rift_projectile`, `rift_arrows` |
| Поглощение | уходит во внешнее кольцо, пока идёт канал | `summon_servants`, затем возврат урона |
| Катастрофа | держится ближе, давит арену и не даёт игроку спокойно стоять на ядре | `arena_inferno`, `void_blast`, `void_mark` |

При переходе ниже 50% включается усиленная фаза, ниже 10% — финальный
ритм. Поглощение не делает босса бессрочно неуязвимым: после окончания
канала урон снова проходит обычным путём. Максимум босса — 2500 HP.

## Манёвры и контр-игра

- `RING_ORBIT` — безопасно меняет сторону кольца вокруг ядра.
- `FLANK` / `CROSSCUT` — подходит к игроку с боковой линии, чтобы прямой
  отход оставался полезным.
- `PHANTOM_FEINT` — не чаще одного раза в 8 секунд меняет фланг коротким
  телепортом с частицами `REVERSE_PORTAL` и `END_ROD`. Телепорт разрешён
  только на уже найденную безопасную точку; ядро и вертикальная граница
  недоступны.
- `ABSORPTION_RETREAT` — уходит к внешнему кольцу, а не застывает на ядре.
- `CATASTROPHE_PRESSURE` — держит ближнюю дистанцию, но сохраняет минимум
  от ядра и общий leash в 20 блоков.

Цель ротируется по живым участникам с памятью недавних целей. Босс не
переключается на предметы или мобов и не продолжает старый target после его
выхода из арены. Если Pathfinder не принимает точку, используется один
ограниченный шаг fallback; повторные задачи на каждый манёвр не создаются.

## Заклинания

Каждый cast проходит цепочку `telegraph -> particle flight -> impact` и
получает собственный силуэт: кольцо, спираль, веер стрел, квадратное клеймо,
вертикальная спираль призыва, ломаная молния, два огненных кольца, двойной
след, схлопывающиеся цепи или звуковой импульс. Визуал — только ванильные
частицы, без невидимых предметов и без изменения ванильных текстур.

Каждая задержанная задача проверяет поколение события и валидность босса.
При смене фазы, удалении ядра, смерти босса или рестарте все полёты,
частицы-таймеры, слуги и временные эффекты очищаются.

Для локальной проверки всей цепочки есть `tests/RunEndRiftSpellMatrixLive.ps1`:
он последовательно проверяет 7 заклинаний босса, 4 стабильных заклинания
мини-боссов, 14 фазовых треков и финальную очистку. Скрипт принимает только
`environment: local` и использует изолированный RCON.
