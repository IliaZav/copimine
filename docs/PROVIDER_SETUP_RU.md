# Почта и VK ID: что осталось подключить

Пароли, приватные ключи, SMTP-пароль, сервисные токены и коды входа не присылайте
в чат. Они записываются непосредственно в закрытый файл `/etc/copimine-site.env`
на сервере. Публичные идентификаторы и DNS-записи секретами не являются.

## Что уже подготовлено

- Postfix принимает исходящую почту приложения только на loopback-интерфейсе.
  Открытого SMTP relay нет. Приём почты пользователей и почтовые ящики не созданы.
- OpenDKIM подписывает исходящую почту домена `copimine.ru`, селектор
  `site202610`; приватный ключ хранится только на сервере с правами 0600.
- Письма приложения проходят через очередь PostgreSQL с ограниченным сроком
  действия и повторными попытками. Коды регистрации/восстановления одноразовые;
  публичного локального inbox нет.
- `MAIL_DOMAIN_READY=0`: реальные письма и почтовый вход выключены до проверки
  DNS и контрольной доставки. Вход с паролем доступен.
- VK ID использует серверный authorization-code flow с PKCE S256, случайным
  одноразовым state, привязкой к текущему браузеру и сроком 10 минут. Токены не
  сохраняются в браузере или журнале. Без `VK_CLIENT_ID` сервис выключен.

## Где управлять DNS

Проверенные авторитетные NS домена: `ns1.reg.ru`, `ns2.reg.ru`.
Войдите в [личный кабинет REG.RU](https://www.reg.ru/user/), откройте домен
`copimine.ru` и управление DNS-зоной. Если домен оформлен у другого регистратора,
найдите в его кабинете услугу DNS с указанными серверами имён.

Для собственного исходящего почтового сервера подготовлены записи:

| Имя | Тип | Значение |
|---|---|---|
| `mail` | A | `90.188.117.117` |
| `@` | TXT | `v=spf1 ip4:90.188.117.117 -all` |
| `site202610._domainkey` | TXT | Содержимое `DKIM_PUBLIC_RECORD.txt`: соединить строки внутри кавычек без пробелов между частями ключа |
| `_dmarc` | TXT | `v=DMARC1; p=none; adkim=r; aspf=r` |

SPF следует **объединить с существующей политикой**, если появятся другие
почтовые сервисы; две SPF-записи для одного имени создавать нельзя. Начальная
DMARC-политика предназначена для проверки доставки, затем её можно ужесточить.

PTR для IP должен указывать на `mail.copimine.ru`; PTR настраивает владелец
IP/провайдер сервера, обычная DNS-зона домена его не меняет. Сейчас PTR не был
подтверждён. Без корректного PTR/репутации адреса доставку нельзя гарантировать.
Для транзакционных писем можно вместо собственного внешнего SMTP выбрать
почтового провайдера и указать его SMTP через STARTTLS.

MX не требуется для отправки писем сайтом. Не добавляйте MX на этот сервер,
пока отдельно не настроены защищённый приём почты, ящики и резервирование.

Что сообщить мне после настройки: название DNS-провайдера, факт добавления
записей, адрес вашей почты для контрольного письма и результат запроса PTR
провайдеру. Если выбираете внешний SMTP — название сервиса, адрес сервера,
порт и логин; пароль запишите в закрытый серверный env-файл.
После проверки SPF/DKIM/DMARC/PTR и контрольного письма включается
`MAIL_DOMAIN_READY=1`, затем перезапускаются API и worker.

## Создание приложения VK ID

1. Откройте [кабинет VK ID для бизнеса](https://id.vk.ru/about/business/go/)
   и создайте приложение с платформой Web.
2. Укажите основной домен `https://copimine.ru` и точный redirect URL
   `https://copimine.ru/api/v6/auth/vk/callback`.
3. Выберите поток с authorization code и PKCE. Реализация опирается на
   [официальный SDK VK](https://github.com/VKCOM/vkid-web-sdk/blob/master/src/auth/auth.ts).
4. Сообщите числовой ID приложения и подтвердите, что callback сохранён.
   ID будет записан в `VK_CLIENT_ID`. Старый client secret для стандартного
   PKCE-потока не используется; дополнительные режимы конфиденциального
   приложения требуют отдельной сверки настроек VK.
5. После включения проведём реальный вход, отказ в разрешениях, повтор callback,
   привязку к существующему аккаунту и конфликт уже занятого VK-профиля.

Автоматического объединения аккаунтов по совпавшей почте нет. Привязать VK
к существующему аккаунту можно только из подтверждённого сеанса. Если для
аккаунта включена 2FA, вход через VK без второго фактора отклоняется; доступен
вход с паролем и кодом приложения.

До создания приложения реальный вход VK и внешняя доставка писем не проверены.
